## 重点项目

### Deep Dive Agent · 团队分析经验产品化

将电商团队的分析方法、指标口径、数据入口与交付规范沉淀为场景化 Skill，为不同业务角色提供经营诊断、对象清单与行动建议。产品重点是团队资产沉淀、分析流程复用和可追溯交付。内部团队数据、截图与系统入口不包含在本公开仓库中。

### 待学 · 从学习灵感到行动

围绕学习灵感难以落地的问题，设计“记录—检索—规划—日历安排—完成反馈”的执行闭环，重点优化工具衔接、任务状态和授权体验。

[体验待学](https://daixue-learning-loop.purple-zebra-9609.chatgpt.site/)

### 轻卡 · 降低饮食记录门槛

从食堂与外卖的真实饮食场景出发，通过目测份量、油量和甜度降低记录门槛，并围绕 AI 异步分析、营养数据联动与结果可理解性持续优化。

[体验轻卡](https://qingka-calorie.purple-zebra-9609.chatgpt.site/)

### 片语 Scene Notes · 影视场景语言学习

从自身学习日语、泰语的需求出发，以影视场景为学习单元，串联台词理解、连续读写、录音回听与词汇回跳，通过开源能力复用和实际体验反馈，完善从兴趣输入到表达练习的学习路径。

[体验片语](https://scene-notes-ja-th.purple-zebra-9609.chatgpt.site/)

## 作品集的维护

作品集本身也是持续维护的产品：围绕招聘者与日常使用者组织项目分类、真实预览、体验入口和设计思路，通过 Vibe Coding 完成需求拆解、交互设计、开发调试与版本迭代，同时维护项目资料、代码归档、链接与预览可用性及多格式展示。
